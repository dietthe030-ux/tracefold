Verified cause: `contracts/tracefold.py` collects package coordinates from public advisories and assigns `UNRELATED` whenever the union has more than one coordinate. The official GHSA for the tested alias pair lists five distinct Maven package coordinates inside one advisory. A multi-package advisory is not evidence of different vulnerability identities. The following SAME authorization guard turns the valid explicit alias into `DISTINCT` solely because of that false `UNRELATED` classification.

Before → after: package relation must reflect publisher-level compatibility rather than raw coordinate cardinality. One publisher with multiple affected packages cannot establish `UNRELATED`. When both GHSA and OSV provide package sets, a shared exact coordinate proves overlap; disjoint sets alone are ambiguous in a multi-package advisory and must not erase an explicit publisher-declared alias. `UNRELATED` remains available only for independently demonstrated contradiction at the vulnerability identity level; the contract must not manufacture that contradiction from package-count alone. An explicit alias is necessary but still not sufficient for SAME: two independently retrieved exact records, the unchanged model semantic decision, full validator agreement and objection guard remain in force.
