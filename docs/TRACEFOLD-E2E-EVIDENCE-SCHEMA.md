# Tracefold live evidence schema

Every deploy/write row records: case and requirement; exact operation ID; selected tool/version and actor; network alias/RPC/chain; contract/source SHA-256; method and non-secret arguments; fee-profile hash, estimate distribution and feeValue; returned GenLayer transaction hash; outer EVM inclusion transaction/receipt and sender/origin; GenLayer lifecycle projection including status and resolution action; stored `FINALIZED`; current-interface semantic result (`isSuccessful` / `FINISHED_WITH_RETURN`) or exact expected rollback; consensus/finality result; authoritative pre/post method readback; actual result and PASS/FAIL. All observations bind the same operation/hash. A timeout resumes observation; it never causes resubmission.

Deployment additionally requires `getContractCode` byte parity and constructor/upgrader readback. Expected rejection requires the exact failure plus unchanged authoritative state.

Studio Dev reset signal: canonical network identity differs, the recorded address has missing code/schema, or authoritative expected state disappears without a Task operation. Preserve source commit/hash, constructor, actor alias/address, operation journals and prior evidence as historical. Classify as external network reset; do not claim durable state. Re-run readiness/balance and PRE_DEPLOY authorization as applicable, deploy once through a new governed replacement operation, verify source parity, rebind frontend contract configuration, invalidate every address-dependent Studio/Vercel/live claim, then regenerate dependent E2E and review evidence.
